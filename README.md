# Portfolio — Sarra Amri

Built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/), deployed to GitHub
Pages by the workflow in `.github/workflows/deploy.yml` on every push to `main`.

## Local preview

```bash
pip install mkdocs-material
mkdocs serve
# → http://127.0.0.1:8000
```

## Structure

- `mkdocs.yml` — site config, theme, navigation
- `docs/` — all content (Markdown)
- `docs/assets/` — screenshots and the CV PDF
- `docs/stylesheets/extra.css` — brand colors and badges
